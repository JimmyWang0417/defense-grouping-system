# 安装与首次登录

本页说明单机 SQLite 模式。SQLite 是保存在一个文件中的数据库，适合课程演示、开发和单机使用。
服务器部署请阅读 [PostgreSQL 服务器迁移](https://github.com/JimmyWang0417/defense-grouping-system/blob/main/docs/operations/server-migration.md)。

## 1. 准备软件

当前版本从源码运行，需要：

- Python 3.12、3.13 或 3.14；
- `uv`，用于按照锁文件安装确定版本的依赖；
- Git，用于取得代码和更新版本。

在仓库根目录执行：

```bash
uv sync --locked
```

`--locked` 表示必须使用 `uv.lock` 中已经确定的版本。如果锁文件和项目配置不一致，命令会直接失败，而不是临时选择其他版本。

## 2. 创建本地配置

```bash
cp .env.example .env
```

打开 `.env`，至少修改：

```text
DEFENSE_JWT_SECRET=一段至少32字符且不能公开的随机字符串
```

这个值用于签发登录凭证。不要把真实值发到聊天、截图或 Git 仓库中。其他常用配置：

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `DEFENSE_DATABASE_URL` | `sqlite+aiosqlite:///./data/defense_grouping.db` | 数据库文件或 PostgreSQL 地址 |
| `DEFENSE_API_HOST` | `127.0.0.1` | API 监听地址；单机使用不要改成公网地址 |
| `DEFENSE_API_PORT` | `8765` | API 端口 |
| `DEFENSE_DISPLAY_TIMEZONE` | `Asia/Shanghai` | 页面显示时间使用的时区 |
| `DEFENSE_STORAGE_DIR` | `./data/storage` | 导入文件、备份等文件的目录 |

## 3. 建表并创建第一个管理员

```bash
uv run alembic upgrade head
uv run defense-grouping init-admin --username admin
```

第一条命令把数据库结构更新到当前版本。第二条命令创建系统管理员，并在终端中显示一次临时密码。

请立即保存临时密码。首次登录后，系统会要求修改密码。再次执行同一个管理员创建命令不会重置已有管理员密码。

## 4. 启动

推荐使用一条命令同时启动 API 和 Flet 客户端：

```bash
uv run python scripts/dev.py
```

启动过程如下：

1. 如果 `.runtime/local.env` 不存在，脚本生成本机配置和随机密钥，并把文件权限设为 `0600`。
2. 启动 FastAPI 后端接口服务。
3. 访问 `http://127.0.0.1:8765/api/v1/health`，确认后端接口服务可以响应。
4. 健康检查成功后启动 Flet 客户端。
5. 关闭客户端或按 `Ctrl+C` 时，同时停止两个进程。

也可以分别启动：

```bash
uv run uvicorn defense_grouping.api.main:create_app --factory --port 8765
DEFENSE_API_URL=http://127.0.0.1:8765 uv run flet run main.py
```

## 5. 首次登录后的设置

用 `admin` 和刚才的临时密码登录。完成强制改密后，按以下顺序设置：

1. 在“系统管理”中创建院系。
2. 创建教务管理员账号，把角色范围限制到对应院系。
3. 如果该教务管理员负责审批例外，开启例外审批权限。
4. 由教务管理员继续录入本院系的专业、方向、教师、学生和教室。

教师账号需要与教师资料关联。只有关联后的教师账号才能看到“我的安排”并确认答辩任务。

## 6. 登录状态是否保留

Web 版会在当前浏览器中保留登录状态。刷新页面、关闭标签页后重新打开，或者 Web 界面服务
重启后，同一浏览器会自动恢复登录。系统不保存密码，只保存一个可由服务器撤销、每次恢复时
都会更换的登录凭据。默认最长有效期为 30 天。

主动点击右上角用户菜单中的“退出登录”后，本地记录和服务器凭据都会失效。管理员停用账号、
重置密码，或者用户自己修改密码，也会使旧凭据失效。清除浏览器站点数据或使用已关闭的无痕
窗口后，也需要重新登录。

公用电脑使用完必须点击“退出登录”，只关闭标签页不会退出。桌面版把同一种登录凭据保存在
操作系统密钥环中，也不会保存密码。维护人员可阅读
[登录状态如何保存](https://github.com/JimmyWang0417/defense-grouping-system/blob/main/docs/operations/login-session.md)。

## 7. 确认安装结果

健康检查：

```bash
curl http://127.0.0.1:8765/api/v1/health
```

SQLite 模式应返回类似：

```json
{"status":"ok","database":"sqlite"}
```

如果页面打不开，请先检查终端中 API 是否提前退出，再查看 [常见问题](常见问题.md)。
