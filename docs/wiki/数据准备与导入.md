# 数据准备与导入

系统提供六类 Excel 模板：学生、教师、课程占用、请假、答辩时段和教室。模板第一行字段名不能改，工作表名称也不能改。

## 导入前的准备顺序

建议按下面的顺序准备数据，避免引用不存在的记录：

1. 创建院系。
2. 创建专业和专业方向。
3. 导入或录入教师。
4. 导入学生，因为学生记录需要引用专业、方向和导师工号。
5. 导入课程占用和请假。
6. 创建答辩活动。
7. 导入答辩时段和教室，或在页面中逐条录入。

## 通用导入步骤

1. 进入“数据导入”。
2. 选择数据类型并下载模板。
3. 只在模板指定的工作表中填写数据，不要新增宏。
4. 上传 `.xlsx` 文件。
5. 点击“检查”。系统读取文件并生成检查结果，此时不会修改正式数据。
6. 根据“工作表、行号、字段、说明”修改错误。
7. 重新上传并检查，直到没有错误。
8. 核对“新增、更新、不变”的数量。
9. 点击“确认导入”，系统才会在一个数据库事务中写入全部数据。

“一个数据库事务”表示同一批数据要么全部成功，要么全部不写入。不会出现只导入前几行、后几行失败的情况。

文件上限为 20 MiB。只接受 `.xlsx`，不接受带宏的 `.xlsm`。

## 学生模板

字段：`学号`、`姓名`、`院系`、`专业`、`年级`、`专业方向`、`导师工号`。

填写要求：

- 学号在系统中必须唯一；
- 院系、专业和专业方向使用系统中已经存在的名称；
- 导师工号必须对应已存在且属于同一院系的教师；
- 一个学生可以有多个专业方向时，按照模板填写说明中的分隔方式填写；
- 不要把空白占位行当作数据行。

重复导入同一学号时，系统把它识别为更新，不会创建第二名学生。确认前要查看更新数量，避免误改已有资料。

## 教师模板

字段：`工号`、`姓名`、`院系`、`职称`、`专业方向`、`工作量上限`。

填写要求：

- 工号必须唯一；
- 职称文字用于显示，职称等级在页面规则中用于判断组长资格；
- 专业方向必须已经创建；
- 工作量上限填写正整数，表示该教师在一个活动中最多参加多少个答辩组。

导师也属于教师数据。自动排组会阻止导师进入自己学生所在的答辩组，除非存在准确且已批准的例外。

## 课程占用模板

字段：`人员编号`、`人员类型`、`日期或教学周`、`星期`、`开始节次`、`结束节次`。

人员编号是学号或工号。人员类型必须明确填写学生或教师。开始节次不能晚于结束节次。

课程占用会转换为不可安排的时间范围。设置答辩时段后，系统按实际时间重叠判断，不是只比较文字。

## 请假模板

字段：`人员编号`、`人员类型`、`开始时间`、`结束时间`、`原因`。

开始和结束时间要包含完整日期与时间，结束时间必须晚于开始时间。原因会进入管理记录，不要填写密码、身份证号等与请假无关的信息。

## 答辩时段模板

字段：`活动`、`日期`、`开始时间`、`结束时间`、`最大组数`。

- 活动名称必须与已创建活动一致；
- 同一活动的时段不能重叠；
- 最大组数表示该时段允许同时安排的答辩组数量；
- 时段容量还会受到可用教室数量限制。

## 教室模板

字段：`校区`、`楼宇`、`教室`、`容量`、`可用日期时段`。

同一校区、楼宇和教室名称的组合不能重复。容量不能小于答辩组学生人数。导入教室后，还需要把它加入具体答辩活动的“可用教室”。

## 如何阅读检查结果

每个问题至少包含：

- 工作表：问题所在的 Excel 页；
- 行号：原文件中的实际行号；
- 字段：具体列名；
- 严重程度：错误必须修复，警告需要人工确认；
- 说明：例如“导师工号不存在”或“同一文件内学号重复”。

不要只删除报错行后直接确认。如果报错说明主数据缺失，应先补齐主数据，再重新检查原文件。

## 导入后检查

确认导入后：

1. 到对应列表检查总数。
2. 搜索一条新增记录和一条更新记录。
3. 检查院系、方向、导师等关联关系。
4. 在审计页面按导入批次查询操作记录。
5. 保留原始文件和导入结果，但不要把含个人信息的文件提交到 Git 仓库。
